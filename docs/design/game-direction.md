# Game Direction

## Working Pitch

Zync Zone Zero is a Steam PC rhythm action combat game where music timing directly controls combat advantage, enemy pressure, and combo flow.

## Core Pillars

- Rhythm is combat logic, not background flavor.
- Combat must remain readable under musical pressure.
- Timing success should change tactical options, not only score.
- Enemies should express rhythm through movement, attacks, and telegraphs.

## Early Design Risks

- Rhythm inputs can fight against action-game responsiveness.
- Visual overload can make timing unreadable.
- Music variety can break combat consistency.
- Boss patterns may become memorization-heavy if not modular.
