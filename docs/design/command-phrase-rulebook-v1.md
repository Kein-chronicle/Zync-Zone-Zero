# Command Phrase Rulebook V1

## 목적

이 문서는 Zync Zone Zero의 4박 커맨드 전투 규칙을 고정한다.

이 문서의 커맨드는 예시가 아니라 1차 구현 기준의 실제 룰이다.

## 기본 원칙

- 커맨드는 항상 4토큰으로 구성한다.
- 4토큰 입력 중 각 토큰은 입력 즉시 해당 행동을 발생시킨다.
- 4토큰이 모두 입력되면 하나의 `Command Phrase`로 해석한다.
- 해석 결과는 다음 4박의 전투 성격, 보너스, 캐릭터 전환, 필살 여부를 결정한다.
- 정식 커맨드는 4토큰 중 태그 토큰을 1~2개 포함해야 한다.
- 태그 토큰이 없는 4토큰 입력은 정식 커맨드가 아니라 `Free Attack Phrase`로 처리한다.
- 태그 토큰이 3개 이상이면 `Broken Phrase`로 처리한다.

## 토큰 정의

| Token | 입력 | 의미 |
|---|---:|---|
| `W` | `J` | 약공격 |
| `H` | `K` | 강공격 |
| `D` | `L` | 회피 |
| `TL` | `Z` | 좌측 태그 |
| `TR` | `X` | 우측 태그 |
| `U` | `I` | 필살기 토큰 |

## 태그 규칙

태그는 단순 방어 버튼이 아니라 실제 행동 캐릭터를 고르는 선택지다.

- `TL`은 현재 전열 기준 좌측 대기 캐릭터를 호출한다.
- `TR`은 현재 전열 기준 우측 대기 캐릭터를 호출한다.
- 태그 토큰이 입력된 박자에는 태그 진입 모션이 즉시 발생한다.
- 태그 이후의 `W`, `H`, `D`, `U`는 새로 들어온 캐릭터가 수행한다.
- 커맨드 종료 시 마지막으로 태그된 캐릭터가 다음 4박의 기준 캐릭터가 된다.
- 보스 노랑 힌트와 태그 타이밍이 맞으면 태그 공격이 태그 패링으로 강화된다.

## Phrase 등급

### Free Attack Phrase

조건:

- 태그 토큰이 0개

처리:

- 입력 행동은 그대로 발생한다.
- 정식 콤보 보너스는 없다.
- Sync/Zync 보상은 낮다.
- 초보자 실수 또는 임시 공격으로 허용한다.

### Standard Phrase

조건:

- 태그 토큰 1개
- `U` 토큰 없음

처리:

- 정식 콤보로 인정한다.
- 태그 캐릭터가 다음 4박 기준 캐릭터가 된다.
- 캐릭터 특성 보너스가 적용된다.

### Advanced Phrase

조건:

- 태그 토큰 2개
- `U` 토큰 없음

처리:

- 고급 콤보로 인정한다.
- 두 캐릭터가 연속 진입한다.
- 리듬 판정 요구가 높다.
- 성공 시 보상이 크지만 Miss가 섞이면 보너스가 크게 줄어든다.

### Ultimate Phrase

조건:

- 태그 토큰 1개
- `U` 토큰 1개
- Zync 또는 Zero 조건 충족

처리:

- 마지막 태그 캐릭터가 필살기를 사용한다.
- 필살기 컷씬이 발동한다.
- 조건 미충족 시 `Failed Ultimate Phrase`로 처리한다.

### Broken Phrase

조건:

- 태그 토큰 3개 이상
- `U` 토큰 2개 이상
- 등록되지 않은 위험 조합

처리:

- 입력 행동은 발생하지만 콤보 보너스 없음
- Sync 감소
- Zync 획득 없음

## 정식 커맨드 목록

1차 구현의 정식 커맨드는 8개로 제한한다.

### 1. Left Rush

Command:

- `TL W W H`

역할:

- 좌측 캐릭터 진입 기본 공격 루트

효과:

- 안정적인 데미지
- Sync 회복량 높음
- 다음 4박 기준 캐릭터는 좌측 태그 캐릭터

### 2. Right Rush

Command:

- `TR W W H`

역할:

- 우측 캐릭터 진입 기본 공격 루트

효과:

- Left Rush와 동일한 기본형
- 다음 4박 기준 캐릭터는 우측 태그 캐릭터

### 3. Left Break

Command:

- `W TL H H`

역할:

- 좌측 캐릭터로 강공 마무리

효과:

- 데미지 중간
- 그로기 축적 높음
- 마지막 `H`가 Perfect면 추가 그로기

### 4. Right Break

Command:

- `W TR H H`

역할:

- 우측 캐릭터로 강공 마무리

효과:

- Left Break와 동일한 구조
- 우측 캐릭터의 그로기 특성 적용

### 5. Left Evasive Counter

Command:

- `D TL W H`

역할:

- 회피 후 좌측 캐릭터 반격

효과:

- 보스 빨강 힌트 대응용
- 첫 `D`가 Good 이상이면 피해 회피 안정성 증가
- 다음 4박 기준 캐릭터는 좌측 태그 캐릭터

### 6. Right Evasive Counter

Command:

- `D TR W H`

역할:

- 회피 후 우측 캐릭터 반격

효과:

- Left Evasive Counter와 동일한 구조
- 우측 캐릭터 특성 적용

### 7. Cross Tag Assault

Command:

- `TL W TR H`

역할:

- 좌측 캐릭터 진입 후 우측 캐릭터 마무리

효과:

- 태그 2회 고급 콤보
- 데미지와 Zync 획득 높음
- Miss가 1회라도 있으면 보너스 반감
- 다음 4박 기준 캐릭터는 우측 태그 캐릭터

### 8. Reverse Cross Assault

Command:

- `TR W TL H`

역할:

- 우측 캐릭터 진입 후 좌측 캐릭터 마무리

효과:

- Cross Tag Assault의 반대 방향
- 다음 4박 기준 캐릭터는 좌측 태그 캐릭터

## 필살기 커맨드

필살기는 기본 2개만 사용한다.

### Left Zync Ultimate

Command:

- `W H TL U`

조건:

- Zync 100 이상 또는 Zero Field 필살 가능 상태

효과:

- 좌측 태그 캐릭터가 필살기 사용
- 필살기 컷씬 2초 발동
- Zync 소비 또는 Zero Field 1회 사용 처리

조건 미충족:

- 필살 컷씬 없음
- `Left Break`보다 약한 태그 강공으로 대체
- `ULT FAILED` 피드백 표시

### Right Zync Ultimate

Command:

- `W H TR U`

조건:

- Zync 100 이상 또는 Zero Field 필살 가능 상태

효과:

- 우측 태그 캐릭터가 필살기 사용
- 필살기 컷씬 2초 발동
- Zync 소비 또는 Zero Field 1회 사용 처리

조건 미충족:

- 필살 컷씬 없음
- `Right Break`보다 약한 태그 강공으로 대체
- `ULT FAILED` 피드백 표시

## 보스 힌트 대응 규칙

보스는 플레이어가 현재 4박 커맨드를 입력하고 있는 동안 다음 위험을 미리 보여준다.

### 노랑 힌트

의도:

- 다음 커맨드에 태그 패링을 준비하게 만든다.

권장 대응:

- `W TL H H`
- `W TR H H`
- `TL W TR H`
- `TR W TL H`

판정:

- 노랑 impact와 태그 토큰 타이밍이 맞으면 태그 패링
- 맞지 않으면 일반 태그 공격

### 빨강 힌트

의도:

- 다음 커맨드에 회피 기반 루트를 선택하게 만든다.

권장 대응:

- `D TL W H`
- `D TR W H`

판정:

- 첫 `D`가 Good 이상이면 회피 성공
- Perfect면 반격 보너스

## 실패 처리

### Miss 포함

- 1 Miss: 콤보 보너스 50% 감소
- 2 Miss 이상: Phrase 실패
- 4 Miss: Broken Phrase

### Bad 포함

- Bad는 콤보를 깨지는 않지만 보너스를 낮춘다.
- Advanced Phrase는 Bad가 2개 이상이면 Standard 보상으로 강등된다.

### 태그 타이밍 실패

- 노랑 공격 대응에 실패해도 태그 자체는 진행된다.
- 단, 태그 패링 보너스는 없다.

## 캐릭터 특성 연결 기준

커맨드 룰은 캐릭터 개성을 위한 기반이다.

이후 캐릭터별 특성은 다음 방식으로 붙인다.

- Z-04: `Break`, `Ultimate`, Perfect 보너스 강화
- Z-05: `Rush`, `Cross Tag`, 연타 유지 보너스 강화
- Z-06: `Evasive Counter`, 회피 안정성, 태그 보조 효과 강화

## 구현 우선순위

1. 4토큰 버퍼 UI
2. 토큰 기록과 4박 단위 phrase 판정
3. 위 8개 정식 커맨드 인식
4. 필살기 단독 `I` 발동 제거
5. `W H TL U`, `W H TR U` 필살기 발동
6. 태그 토큰 기준 실제 행동 캐릭터 변경
7. 보스 노랑/빨강 힌트와 추천 대응 연결
8. Phrase 성공/실패 피드백

## 최종 규칙

1차 버전에서 플레이어가 외워야 할 것은 많지 않아야 한다.

기본 공격:

- `TL W W H`
- `TR W W H`

강공/그로기:

- `W TL H H`
- `W TR H H`

회피 반격:

- `D TL W H`
- `D TR W H`

고급 태그:

- `TL W TR H`
- `TR W TL H`

필살기:

- `W H TL U`
- `W H TR U`

이 정도가 1차 구현 한계다. 더 늘리면 재미보다 암기 부담이 먼저 온다.
