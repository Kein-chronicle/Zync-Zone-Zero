# Combat Command Rulebook

## Status

This is the canonical rulebook for the next combat-system implementation.

It replaces these removed draft documents:

- `docs/design/command-phrase-combat-mechanic.md`
- `docs/design/command-phrase-rulebook-v1.md`

Use this document when implementing command buffers, phrase recognition, tag direction, ultimate activation, and boss hint response.

## 목적

이 문서는 Zync Zone Zero의 4박 커맨드 전투 규칙을 고정한다.

이 문서의 커맨드는 예시가 아니라 1차 구현 기준의 실제 룰이다.

## 전투 루프

Zync는 파타퐁처럼 4박 동안 기다렸다가 다음 4박에만 행동하지 않는다.

Zync의 4박 커맨드는 다음처럼 작동한다.

1. 현재 4박 동안 플레이어가 커맨드를 입력한다.
2. 각 입력은 그 박자에 즉시 행동으로 발생한다.
3. 동시에 입력 토큰은 4칸 커맨드 버퍼에 쌓인다.
4. 4번째 입력이 끝나면 버퍼 조합을 해석한다.
5. 해석 결과는 다음 4박의 전투 성향, 보너스, 캐릭터 전환, 필살 여부를 결정한다.
6. 보스는 현재 행동 중 다음 공격의 노랑/빨강 힌트를 미리 보여준다.
7. 플레이어는 그 힌트를 보고 다음 4박 커맨드를 선택한다.

커맨드 버퍼는 "나중에 실행할 명령"이 아니라 "현재 4박 동안 실제로 수행한 액션의 문장"이다.

## 핵심 수정 원칙

태그 방향을 커맨드 룰에서 강제하지 않는다.

잘못된 방식:

- `TL W W H`
- `TR W W H`

이 방식은 플레이어가 어떤 캐릭터를 선출할지 계산하는 재미를 죽인다.

올바른 방식:

- `T W W H`

여기서 `T`는 태그 슬롯이다.

실제 입력 순간 플레이어가 `Z`를 누르면 좌측 태그, `X`를 누르면 우측 태그가 된다.

즉, 커맨드 룰은 "태그가 필요하다"만 정의하고, 방향 선택은 플레이어가 한다.

## 기본 원칙

- 커맨드는 항상 4토큰으로 구성한다.
- 4토큰 입력 중 각 토큰은 입력 즉시 해당 행동을 발생시킨다.
- 4토큰이 모두 입력되면 하나의 `Command Phrase`로 해석한다.
- 해석 결과는 다음 4박의 전투 성격, 보너스, 캐릭터 전환, 필살 여부를 결정한다.
- 정식 커맨드는 4토큰 중 태그 슬롯 `T`를 1~2개 포함해야 한다.
- 태그 슬롯이 없는 4토큰 입력은 정식 커맨드가 아니라 `Free Attack Phrase`로 처리한다.
- 태그 슬롯이 3개 이상이면 `Broken Phrase`로 처리한다.
- 실제 태그 방향은 입력 시점의 `Z` 또는 `X`로 결정한다.

## 토큰 정의

| Rule Token | 실제 입력 | 의미 |
|---|---:|---|
| `W` | `J` | 약공격 |
| `H` | `K` | 강공격 |
| `D` | `L` | 회피 |
| `T` | `Z` 또는 `X` | 태그 슬롯 |
| `U` | `I` | 필살기 토큰 |

## 실제 입력 토큰

내부 구현에서는 태그 방향을 보존해야 한다.

| Internal Token | 입력 | 의미 |
|---|---:|---|
| `TL` | `Z` | 좌측 태그 |
| `TR` | `X` | 우측 태그 |

룰 매칭에서는 `TL`과 `TR`을 모두 `T`로 취급한다.

다만 실행 결과에서는 방향을 유지한다.

예:

- 룰: `T W W H`
- 입력: `TL W W H`
- 결과: 좌측 캐릭터 선출

예:

- 룰: `T W W H`
- 입력: `TR W W H`
- 결과: 우측 캐릭터 선출

## 태그 규칙

태그는 단순 방어 버튼이 아니라 실제 행동 캐릭터를 고르는 선택지다.

- `Z`는 현재 전열 기준 좌측 대기 캐릭터를 호출한다.
- `X`는 현재 전열 기준 우측 대기 캐릭터를 호출한다.
- 태그 토큰이 입력된 박자에는 태그 진입 모션이 즉시 발생한다.
- 태그 이후의 `W`, `H`, `D`, `U`는 새로 들어온 캐릭터가 수행한다.
- 커맨드 종료 시 마지막으로 태그된 캐릭터가 다음 4박의 기준 캐릭터가 된다.
- 보스 노랑 힌트와 태그 타이밍이 맞으면 태그 공격이 태그 패링으로 강화된다.

## Phrase 등급

### Free Attack Phrase

조건:

- 태그 슬롯 0개

처리:

- 입력 행동은 그대로 발생한다.
- 정식 콤보 보너스는 없다.
- Sync/Zync 보상은 낮다.
- 임시 공격 또는 실수 입력으로 허용한다.

### Standard Phrase

조건:

- 태그 슬롯 1개
- `U` 토큰 없음

처리:

- 정식 콤보로 인정한다.
- 실제 태그 방향에 따라 행동 캐릭터가 결정된다.
- 캐릭터 특성 보너스가 적용된다.

### Advanced Phrase

조건:

- 태그 슬롯 2개
- `U` 토큰 없음

처리:

- 고급 콤보로 인정한다.
- 두 캐릭터가 연속 진입한다.
- 첫 번째 태그와 두 번째 태그 방향은 플레이어가 각각 선택한다.
- 마지막 태그 캐릭터가 다음 4박 기준 캐릭터가 된다.
- 성공 보상은 크지만 Miss가 섞이면 보너스가 크게 줄어든다.

### Ultimate Phrase

조건:

- 태그 슬롯 1개
- `U` 토큰 1개
- Zync 또는 Zero 조건 충족

처리:

- 실제 태그 방향으로 선택된 캐릭터가 필살기를 사용한다.
- 필살기 컷씬이 발동한다.
- 조건 미충족 시 `Failed Ultimate Phrase`로 처리한다.

### Broken Phrase

조건:

- 태그 슬롯 3개 이상
- `U` 토큰 2개 이상
- 등록되지 않은 위험 조합

처리:

- 입력 행동은 발생하지만 콤보 보너스 없음
- Sync 감소
- Zync 획득 없음

## 정식 커맨드 목록

1차 구현의 정식 커맨드는 5개로 제한한다.

방향은 커맨드가 아니라 플레이어 입력으로 결정한다.

### 1. Rush

Command:

- `T W W H`

역할:

- 태그 캐릭터 진입 기본 공격 루트

효과:

- 안정적인 데미지
- Sync 회복량 높음
- 다음 4박 기준 캐릭터는 실제 태그 방향으로 들어온 캐릭터

### 2. Break

Command:

- `W T H H`

역할:

- 공격 중 태그 후 강공 마무리

효과:

- 데미지 중간
- 그로기 축적 높음
- 마지막 `H`가 Perfect면 추가 그로기
- 노랑 힌트 대응용 태그 패링 후보

### 3. Evasive Counter

Command:

- `D T W H`

역할:

- 회피 후 태그 캐릭터 반격

효과:

- 보스 빨강 힌트 대응용
- 첫 `D`가 Good 이상이면 피해 회피 안정성 증가
- Perfect면 반격 보너스
- 다음 4박 기준 캐릭터는 실제 태그 방향으로 들어온 캐릭터

### 4. Cross Tag Assault

Command:

- `T W T H`

역할:

- 두 캐릭터가 연속 진입하는 고급 태그 공격

효과:

- 태그 2회 고급 콤보
- 데미지와 Zync 획득 높음
- 첫 태그와 두 번째 태그 방향은 플레이어가 선택
- 마지막 태그 캐릭터가 다음 4박 기준 캐릭터
- Miss가 1회라도 있으면 보너스 반감

### 5. Zync Ultimate

Command:

- `W H T U`

역할:

- 태그 캐릭터 필살기

조건:

- Zync 100 이상 또는 Zero Field 필살 가능 상태

효과:

- 실제 태그 방향으로 선택된 캐릭터가 필살기 사용
- 필살기 컷씬 2초 발동
- Zync 소비 또는 Zero Field 1회 사용 처리

조건 미충족:

- 필살 컷씬 없음
- 약한 태그 강공으로 대체
- `ULT FAILED` 피드백 표시

## 보스 힌트 대응 규칙

보스는 플레이어가 현재 4박 커맨드를 입력하고 있는 동안 다음 위험을 미리 보여준다.

### 노랑 힌트

의도:

- 다음 커맨드에 태그 패링을 준비하게 만든다.

권장 대응:

- `W T H H`
- `T W T H`

판정:

- 노랑 impact와 실제 태그 토큰 타이밍이 맞으면 태그 패링
- 맞지 않으면 일반 태그 공격

### 빨강 힌트

의도:

- 다음 커맨드에 회피 기반 루트를 선택하게 만든다.

권장 대응:

- `D T W H`

판정:

- 첫 `D`가 Good 이상이면 회피 성공
- Perfect면 반격 보너스

## 실패 처리

### Miss 포함

- 1 Miss: 콤보 보너스 50% 감소
- 2 Miss 이상: Phrase 실패
- 4 Miss: Broken Phrase

### Bad 포함

- Bad는 콤보를 깨지는 않지만 보너스를 낮춘다.
- Advanced Phrase는 Bad가 2개 이상이면 Standard 보상으로 강등된다.

### 태그 타이밍 실패

- 노랑 공격 대응에 실패해도 태그 자체는 진행된다.
- 단, 태그 패링 보너스는 없다.

## 캐릭터 특성 연결 기준

커맨드 룰은 캐릭터 개성을 위한 기반이다.

이후 캐릭터별 특성은 다음 방식으로 붙인다.

- Z-04: `Break`, `Ultimate`, Perfect 보너스 강화
- Z-05: `Rush`, `Cross Tag Assault`, 연타 유지 보너스 강화
- Z-06: `Evasive Counter`, 회피 안정성, 태그 보조 효과 강화

중요:

- 캐릭터 선택은 커맨드 룰이 아니라 태그 방향 입력으로 결정한다.
- 같은 `T W W H`라도 `Z`를 누르면 좌측 캐릭터 루트, `X`를 누르면 우측 캐릭터 루트다.

## 구현 우선순위

1. 키 입력을 `event.code` 기준으로 처리한다.
2. 4토큰 버퍼 UI를 만든다.
3. 내부 입력은 `TL`, `TR`로 저장한다.
4. 룰 매칭 시 `TL`, `TR`을 `T`로 정규화한다.
5. 위 5개 정식 커맨드를 인식한다.
6. 필살기 단독 `I` 발동을 제거한다.
7. `W H T U` 필살기 발동을 추가한다.
8. 태그 방향 기준으로 실제 행동 캐릭터를 변경한다.
9. 보스 노랑/빨강 힌트와 추천 대응을 연결한다.

## 최종 1차 커맨드

플레이어가 외울 커맨드는 5개다.

- `T W W H`: 기본 태그 공격
- `W T H H`: 강공/그로기
- `D T W H`: 회피 반격
- `T W T H`: 고급 2태그 공격
- `W H T U`: 필살기

여기서 `T`는 항상 플레이어가 `Z` 또는 `X`로 선택한다.

이 구조가 있어야 플레이어가 선출 캐릭터를 계산할 수 있다.
