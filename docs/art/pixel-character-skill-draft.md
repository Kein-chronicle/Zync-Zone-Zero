# Pixel Character Generation Skill Draft

## Goal

Create attractive pixel-art character sheets first, then convert selected designs into code-native `PixelFrame` data.

## Workflow

1. Generate one polished concept sheet per character.
2. Judge silhouette, face appeal, pose appeal, and palette.
3. Pick one design direction.
4. Convert the chosen character into frame data.
5. Render frames in the game using code.

## Quality Bar

A generated sheet is only acceptable if:

- the character is attractive at first glance
- the silhouette is readable
- the face has appealing anime features
- the back view is still recognizable
- the outfit works in pixel art
- attack poses are different from each other
- the result does not resemble a ZZZ character directly
