# Character Sheet Prompts

## Purpose

Standard prompts for generating consistent pixel-art character sheets for Zync Zone Zero.

These prompts are for concept sheets, not final sprite sheets. The goal is to establish readable silhouettes, role identity, outfit direction, and repeatable pose categories.

## Shared Sheet Format

Use this structure for every playable character:

- One clean character design sheet.
- Pixel art concept style.
- Adult-coded anime heroine proportions.
- Fixed sheet layout with labeled rows.
- Neutral background.
- No copyrighted references, no ZZZ character copying.
- Back-view readability is required because the game camera shows the player from behind.

Required sheet rows:

1. Full-body idle: front, back, three-quarter back.
2. Weak attack chain: weak 1, weak 2, weak 3.
3. Heavy attack chain: heavy 1, heavy 2, finisher.
4. Defensive actions: dodge, tag-in, tag parry.
5. Support action: support auto attack, support idle.

## Shared Negative Prompt

Avoid:

- Direct resemblance to any Zenless Zone Zero character.
- School-uniform default design.
- Childlike proportions.
- Excessively revealing outfit.
- Overly complex micro-details that fail in pixel art.
- Blurry painterly rendering.
- 3D render look.
- Text that is too small to read.
- Logos, watermarks, UI overlays.

## Z-01 Prompt

Use case: stylized-concept
Asset type: pixel-art playable character design sheet
Primary request: Create a standardized pixel-art character sheet for Z-01, the balanced lead heroine for a rhythm action boss combat game.
Subject: Adult-coded anime heroine, balanced blade fighter, calm confident combat stance, readable from front and back.
Style/medium: crisp high-resolution pixel art concept sheet, clean sprite-design presentation, game-ready silhouette exploration.
Composition/framing: one sheet with five horizontal rows: full-body idle views; weak attack chain; heavy attack chain; defensive actions; support actions. Keep each pose separated with even spacing.
Character design: short tactical jacket, asymmetrical combat skirt or shorts over leggings, medium blade or baton-sword, compact boots, tied or shoulder-length hair, cyan-white timing accents.
Combat role: stable default character, medium speed, clean slashes, easy-to-read silhouette.
Required poses: front idle, back idle, three-quarter back idle, weak 1 straight slash, weak 2 cross slash, weak 3 spinning finisher, heavy 1 two-handed downward strike, heavy 2 step-in breaker, heavy finisher, dodge side step, tag-in, tag parry impact, support auto slash, support idle.
Color palette: dark neutral base, white/cyan highlights, subtle steel weapon edge, skin/hair colors distinct from effects.
Constraints: adult-coded, original design, strong back-view readability, pixel art only, no copied characters, no logos, no watermark.
Avoid: school uniform, childlike proportions, direct ZZZ character resemblance, excessive detail, painterly rendering, 3D model look.
