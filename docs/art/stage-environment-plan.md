# Stage Environment Plan

## Current Test Stage

The first playable test stage is a code-native pixel city environment.

Runtime file:

- `src/pixelEnvironment.ts`

## Direction

- Urban night combat arena.
- Fixed camera.
- Boss in front, party in foreground.
- Pixel skyline and floor grid.
- Neon pulse reacts to beat.
- Stage warning color can react to enemy attack state.

## Current Elements

- layered dark city skyline
- pixel buildings with window lights
- combat floor band
- perspective floor grid
- beat-pulsed neon rails
- small sign/light accents
- attack warning tint support

## Rules

- Background must not compete with yellow/red attack readability.
- Floor lines should support rhythm/position feel, not become note lanes.
- Stage should be code-generated until the art direction stabilizes.
- Later final pixel background art can be generated from this layout spec.

## Next Stage Ideas

- back-alley neon street
- rooftop rail platform
- corrupted subway terminal
- rain-slick crossing
- alien-infected city block
